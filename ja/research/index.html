    研究概要

    ロボットや人工衛星を目的どおりに動作させるには，機体がどの方向を向くかを制御する必要があります。一方で，実際の機械には必ず守らなければならない制限が存在します。

    • モータが発生できる力には上限があります
    • 観測用のカメラを太陽の方向へ向けることはできません
    • 壁面に押し付けながら走行する機体は，取り得る姿勢が限られます

    制御工学では，こうした制限を拘束と呼びます。本研究室では，拘束を満たしながら回転運動を制御するための理論構築と，実機による検証を研究の中心に据えています。

    主な応用先は，人工衛星とドローンです。

    研究テーマ

    1. 拘束を考慮した回転運動の制御

    回転の表現と特異点

    物体の位置は x, y, z の 3 つの数で表すことができますが，向きの表現はそれほど単純ではありません。

    航空機の姿勢を，機首の上下・左右の傾き・向きの回転という 3 つの角度で表す方法（オイラー角）が広く用いられています。ただしこの表現には，特定の姿勢において計算が破綻するという弱点があります。航空分野やコンピュータグラフィックスの分野で「ジンバルロック」と呼ばれる現象です。

    本研究室では，向きを 3 つの角度に分解せず，回転そのものを直接あつかう数学的な枠組み（回転行列の集まりであり，SO(3) と表記されます）を用いています。この定式化により，あらゆる姿勢において破綻しない制御系設計が可能となります。

    拘束の保証と計算負荷

    拘束を満たすための素朴な方法として，危険な状態に近づいたときに動作を制限する仕組みを後から追加する，という考え方があります。しかしこの方法では，あらゆる状況において拘束が満たされるという保証が得られません。

    本研究室では，Explicit Reference Governor（ERG） および制御バリア関数（CBF） に基づく手法を用いています。これらは，制御器そのものを設計し直すのではなく，制御器に与える目標値を，安全な範囲へあらかじめ加工するという考え方に立つものです。これにより，拘束の充足を保証することができます。

    もう一つの重要な特徴は，動作中に最適化計算を解く必要がないという点です。

    拘束を扱う代表的な手法であるモデル予測制御は，各時刻において最適化問題を解きます。このため，計算能力の限られた機器では実行が困難になります。これに対して ERG や CBF に基づく手法は，あらかじめ導出しておいた式を評価するだけで済むため，小型の計算機でも実装できます。この「最適化を必要としない」枠組みそのものについても，一般的な形で研究を進めています（arXiv, 2026）。

    代表的な成果

    • Explicit reference governor on SO(3) for torque and pointing constraint management — Automatica, 2023
    • Attitude Constrained Control on SO(3): An Explicit Reference Governor Approach — IEEE CDC, 2018
    • Periodic Event-Triggered Explicit Reference Governor for Constrained Attitude Control on SO(3) — arXiv, 2026

    応用：小型衛星の姿勢制御

    人工衛星は，地球を周回しながら姿勢を変更します。この過程では，複数の拘束が同時に課されます。

    • 観測用のカメラを太陽の方向へ向けてはなりません（センサが損傷するためです）
    • 通信用のアンテナは地上局の方向へ向け続ける必要があります
    • 姿勢を変更する装置（リアクションホイール）が発生できるトルクには上限があります

    さらに，衛星に搭載できる計算機は，打ち上げ時の質量制限と宇宙空間の放射線環境への耐性が求められるため，地上の計算機と比べて性能が大きく制限されます。このため，各時刻で最適化問題を解く方式は適用が困難となります。

    前節で述べた最適化を必要としない手法は，このような状況において有効に働きます。現在は，複数の小型衛星が協調して姿勢を変更する枠組みの構築に取り組んでいます。

    科学研究費助成事業 基盤研究(B)（2026–2029年度，課題番号 26K00967）

    「小型衛星群に対するオンライン最適化を用いない制約付き協調姿勢制御の確立」

    本テーマは，佐々木 貴広 氏（宇宙航空研究開発機構 JAXA）ならびに 坂本 登 教授（南山大学）との共同研究として進めています。

    応用：三次元回転機構の制御系設計

    三次元的な回転運動を生み出す機構を対象として，高精度な回転制御の実現を目指した制御系設計に，共同研究として取り組んでいます。

    2. 車輪付きドローンとインフラ点検

    飛行と走行を融合した機体

    ドローンは自由に飛行できる一方で，飛行中の消費電力が大きく，稼働時間が制限されます。また，壁面のごく近傍において姿勢を乱さずに停止し続けることは容易ではありません。

    そこで本研究室では，車輪を備えたドローンを対象としています。壁面や天井に機体を押し付けて車輪で走行し，必要に応じて飛行へ移行する機体です。

    この機体は，制御の観点から次のような難しさを伴います。

    • 車輪は横方向に滑らないため，運動できる方向が制限されます（非ホロノミック拘束と呼びます）
    • 壁面への押し付け力の調整が必要です。押し付け力が不足すれば壁面から離れ，過大であれば機体が跳ね返ります
    • 飛行状態と走行状態が切り替わるため，運動の性質そのものが変化します

    ここでも中心となるのは拘束です。押し付け力，接触時に取り得る姿勢，飛行可能な高度といった制限を扱うために，制御バリア関数，入出力線形化，受動性に基づく手法，モデル予測経路積分制御（MPPI） などを組み合わせています。

    応用：インフラ点検

    トンネルや橋梁，建物の壁面において，タイルの浮きや剥離を調べる作業として，ハンマーで打撃し打撃音を聞き分ける打音検査があります。高所での作業には足場の設置が必要となり，費用と危険を伴います。

    本研究室では，車輪付きドローンを用いて，壁面タイルの打音検査，橋梁支承部（橋桁を支える部分）の点検，天井裏の調査など，人が接近しにくい場所を対象とした点検システムの開発を進めています。

    代表的な成果

    • Development of Wall Hammering Inspection Systems Using Two-Wheeled Multicopters — Journal of Robotics and Mechatronics, 2024
    • 入出力線形化による非ホロノミック拘束を有する車輪付きドローンの壁面上での位置追従制御 — システム制御情報学会論文誌, 2025
    • Stable Haptic Shared Autonomy for Wall Landing of Two-Wheeled Drones via Control Barrier Functions — IEEE IECON, 2025

    人と協調する制御

    すべての動作を自動化するのではなく，操縦者が機体を操作し，危険な動作のみを制御系が防ぐという形態についても研究を進めています。操縦者へ触覚を介して拘束の存在を提示しながら，安全性は理論的に保証する仕組みです。

    その他の応用・共同研究

    上記のほか，共同研究として次のテーマにも参画しています。

    • 建築構造物の振動制御 — 地震や風による建物の揺れを抑制する研究です。等価入力外乱（EID）に基づく外乱推定の考え方を，制振ダンパの設計や免震建物の制御へ応用しています。代表例（Control Engineering Practice, 2024）
    • ビジュアルフィードバック制御 — カメラで取得した画像から対象の位置と姿勢を推定し，制御へ利用する研究です。代表例（SICE JCMSI, 2023）
