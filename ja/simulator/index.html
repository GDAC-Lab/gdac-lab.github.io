    シミュレータ

    車輪付きドローンのシミュレータを公開しています。下のデモは録画ではありません。シミュレータの物理計算を，いまお使いのブラウザの中で実行しています。

    物理エンジンを読み込みますか？

    デモを実行するには，MuJoCo の WebAssembly 版（約 3.5〜12 MB。サーバの圧縮設定によって異なります）をダウンロードします。ブラウザに保存されるため，ダウンロードは初回だけです。

    デモの内容

    4つのロータと2つの車輪を持つ機体です。機体の形状は，研究室の実機を採寸して作成しました。

    壁面を登るときも，特別なことはしていません。壁の奥に目標位置を置くだけです。機体はそこへ向かおうとしますが，壁に阻まれます。目標へ向かおうとする力がそのまま車輪を壁に押し付ける力になり，壁からはそれと釣り合う反力を受けます。車輪は壁の上を転がるので，壁に沿った上下方向には自由に動けます。押し付けるための専用の制御は組み込んでいません。

    姿勢の制御には，回転を3つの角度に分解せず，回転行列のまま扱う定式化を用いています。この定式化には，姿勢の表し方に由来する特異点がなく，どの姿勢でも計算が破綻しないという利点があります。本研究室の研究の中心にある考え方です。詳しくは研究内容のページをご覧ください。

    シミュレータ本体

    単機・複数機のシミュレーションや，壁面・曲面地形での走行に対応しており，実機のフライトコントローラを組み込んだ試験も行えます。ソースコード・ライセンス・引用情報は GitHub で公開しています。
