# Contributing

This repository holds the GDAC Lab website. Lab members: open an issue or a pull request against
`master`; a merge to `master` deploys the live site (see "Deployment" in `README.md`).

Before opening a pull request:

- Read `README.md` for where content lives and how the site is built.
- **Do not hand-edit `_publications/*.md`** — those files are regenerated by the sync scripts and
  your changes will be overwritten. Add preprints to `_data/preprint_sources.json` instead.
- Keep the English and Japanese pages in step (`_pages/` and `_pages/ja/`).
- Resize images to their delivery size before committing; do not commit camera originals.
- Build locally (`bundle exec jekyll serve`) and check the pages you touched in both languages.

## Issues with the underlying template

This site is a fork of [Academic Pages](https://github.com/academicpages/academicpages.github.io).
Bugs in the template itself belong
[upstream](https://github.com/academicpages/academicpages.github.io/issues/new/choose), not here.
