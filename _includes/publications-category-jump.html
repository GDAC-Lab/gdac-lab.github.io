{%- comment -%} Jump buttons across the top of a publications index, one per category. A category gets a button only when it has entries inside the year window — the same test the lists themselves apply, made through publication-recent-count.html so the two cannot drift apart. That count is also printed on the button: on a page that lists every year, the length of a section is what decides whether it is worth scrolling to. The printed count is a bare number with a rule beside it, which reads as "学術雑誌論文11" when spoken, so the button carries a spelt-out aria-label instead. The English page counts English-language works only; the Japanese page shows both languages under one heading per category, so it counts all of them. {%- endcomment -%} {% if site.publication_category %} {%- assign _jump_ja = false -%} {%- if page.lang == 'ja' %}{% assign _jump_ja = true %}{% endif -%}
